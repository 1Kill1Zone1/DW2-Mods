# Testing Cancellation Refunds

Checked against GOG 1.3.8.4 only: 79 native, 26 targeted, and 2 missing-dependency checks. It is not installed and Steam beta is unverified.

1. Use a new GOG 1.3.8.4 disposable campaign and enable Positronic Matrix.
2. Cancel a newly paid ordinary building or troop order and confirm only remaining paid work is refunded.
3. Verify old/unknown orders, upgrades, captures, completed assets, ships, and resources are not refunded.
4. Save/reload a disposable campaign, then compare every release file with SHA256SUMS.

This prerelease does not promise compatibility with other game versions, unrelated mod stacks, GPU rendering, or performance beyond its stated evidence.
